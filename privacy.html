Privacy Policy

Last revised: 20 November 2026 · Applies to the privately operated Grey VPS Runtime environment and its Google Drive integration.

1. Who operates the service

Grey VPS Runtime is a privately managed assistant, note synchronization and backup environment. For inquiries or requests, contact the operator at the support email shown on its Google OAuth consent screen. It is not offered as a public consumer service.

2. Information processed

When an authorized account connects Google Drive, the system may use Google account authorization identifiers, access and refresh tokens, and the names, IDs, metadata and contents of files it is permitted to access. The environment can also process personal notes, selected assistant memory and skills documents, and encrypted backup packages. Operational records may include file IDs, timestamps, checksums and error messages.

3. Purpose and Google API access

The intended Google OAuth scope is https://www.googleapis.com/auth/drive.file, allowing the application to work with files it creates or files the user explicitly opens or shares with it. The service uses this access only to save, verify, retrieve and synchronize owner-authorized notes and backup objects. It is not intended to scan or index the user's whole Google Drive. A future permission change would require separate informed authorization.

4. Storage, encryption and security

Google OAuth credentials are intended to be held in access-restricted configuration on the private host; secrets are not intended to be published on this website. Backup packages may be encrypted before being copied to Google Drive or a private GitHub repository. Some operational notes or configuration metadata may exist outside those encrypted packages. The system currently uses distinct logical assistant workspaces for authorized individuals but can share server processes and service-level credentials; therefore it does not claim strong operating-system isolation.

5. Sharing and third parties

Data is shared with Google services where required to perform authorized Drive operations, with the operator's private hosting provider for infrastructure, and with a private backup repository provider for encrypted archives where configured. Authorized assistant services may process their own permitted information. Personal Google data is not sold or used for advertising. No unrelated third party is authorized to use Google data for independent purposes by this integration.

6. Retention, deletion and access control

Notes and backups are retained according to the operator's configured backup and retention rules; these may preserve historical encrypted snapshots. Requests for deletion or correction can be directed to the developer via the OAuth support email. Account holders can revoke OAuth authorization at Google Account third-party connections. Revoking a token prevents new authorized API access but does not automatically delete previously stored backups or copies.

7. Data protection and limitations

The operator aims to minimize permissions, restrict stored secrets, verify backup integrity and separate individuals' content. No claim of absolute isolation, complete offsite recovery or 24/7 availability is made. Public-facing access is not enabled merely by publishing this information page.

8. Google API Services User Data Policy

Use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements. Google user data will only be used for features described above or otherwise disclosed to and authorized by the user; it will not be transferred to other parties except as needed to provide the requested features, comply with law, protect against fraud or abuse, or with the user's affirmative consent.

9. Changes and contact

This policy can change as the tool evolves. The date at the top will be updated for material changes. The contact channel is the developer support email displayed in the OAuth consent screen.
