Grey VPS Runtime

A privately operated assistant environment for personal automation, note synchronization and encrypted backups.

Access model

This is an owner-operated tool, not a public signup service. Access is restricted to explicitly authorized Google accounts and assistant users. Google OAuth consent is requested only when an authorized account chooses to connect Google Drive.

What the integration does

  • Synchronizes selected personal notes and approved backup files with Google Drive.
  • Uses Google Drive permissions and the scope granted at authorization time; its intended OAuth scope is https://www.googleapis.com/auth/drive.file.
  • Maintains personal assistant workspaces and encrypted backup artifacts in the operator's environment.
  • Allows an authorized user to revoke access using Google Account security settings.

Important limitations

Google Drive access is limited by the granted permissions, OAuth client identity and application configuration. An encrypted backup on Google Drive does not imply that all data stored on the server is independently isolated between users. The service is under active private development and is not offered with a public uptime or security certification.

Contact

Questions about access, privacy or removal requests should be sent to the developer using the support email listed in the Google OAuth consent screen for Grey VPS Runtime.
